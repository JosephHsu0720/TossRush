# 第一關／第四關：目標與場景配色分離

狀態：已依 `Validation/RoomPaletteApply.json` 確認於 2026-11-12 14:31（台北）套用。這是街頭改造前的房間配色紀錄；原第四關房間角落目前移至第一關，街頭採另一組專用材質。實際畫面尚待重新檢查。

## 配色目標

運用暖冷對比、彩度層級與明度差，把注意力集中到垃圾桶。場景以低彩度暖色為主，避免原本大片薄荷綠牆面／椅子與桶口競爭。地板線降低對比，借彈板保留較溫和的赭色，仍可辨認其形狀。

| 用途 | 配色 | 設計目的 |
|---|---|---|
| 牆面、目標後方背景 | 暖米色 `#D4C5B4` | 與冷色垃圾桶分離，保持背景明亮 |
| 地板、木製家具 | 低彩度暖木色 `#AF8B70` | 保留房間感，減少周圍物件搶眼程度 |
| 椅子與次要家具 | 灰褐色 `#B9A68D` | 不再與桶口共用薄荷綠 |
| 借彈板、斜板與小物重點 | 柔和赭色 `#BC885F` | 保留機關辨識度，降低亮黃／珊瑚紅競爭 |
| 深色結構、盆栽 | 暖灰 `#5E5147`／灰橄欖 `#7E8268` | 統一背景色系 |
| 地板裝飾線 | 暖淺褐 `#BFA48C` | 降低高頻線條的視覺干擾 |
| 垃圾桶桶身 | 鈷藍 `#126EBB` | 以較高彩度的冷色形成主焦點 |
| 桶口 | 淡冰藍 `#C3EAF6` | 與深色桶身形成明度差，方便辨認投入口 |
| 目標外框 | 保留目前金色與寬度 | 延續可投擲目標的辨識規則 |

背景材質的邊緣亮度降為 0.02，目標維持 0.06。使用既有 Stage Toon Shader，不增加貼圖、套件或執行期調色元件。

## 套用

1. 退出 Play Mode，讓 Unity 完成新 Editor 腳本匯入。
2. 點選 **TossRush → Apply Room Contrast Palette**。
3. 選單會建立 `Assets/TossRush/Materials/RoomPalette/` 的九個材質，透過 Unity API 更新第一／第四關與兩個垃圾桶 Prefab。第二／第三關與共用基礎材質不會修改。
4. 再次 Play，分別檢查第一與第四關；第四關可暫時將 Starting Stage Index 設成 3，測完改回 0。

成功後會產生 `Docs/Validation/RoomPaletteApply.json`，列出已更新的 Prefab 與 Renderer 數量。原模型、位置隨機範圍、碰撞體、分數與物理設定維持原狀。重複點選會更新同一組專用材質，不會建立重複資產。

## 驗證狀態

- 已用此專案安裝的 Unity 6000.3.11f1 編譯器及 Unity／專案組件，單獨編譯 Editor 套用程式：通過。
- 現有 Editor 連線遭環境拒絕（socket error 10013）；尚無套用報告、Game View 畫面或灰階實景驗證。
