# 夜市套圈圈：留在圈內才計分

2026-11-18 更新規則：圈圈實際套入並穩定留住目標才計分。短暫穿過或套入後立即彈出，不計分，也不將目標變暗。

## 判定

- 保留由上方接近的投擲歷史，允許擦邊後滑入；每次投擲以 LaunchId 區隔，物件池重用不繼承資格。
- 只檢查當下真實圈圈位置與姿態，目標中心軸及該高度完整碰撞截面須在圈洞內。飛行路徑掃描不再直接發分。
- 高度範圍延伸至目標原點下方最多兩個圈管半徑，涵蓋前端抬高的圈圈停在底座周圍（中心略低於原點）的情況。此時沿直立目標軸將腳部截面投影至同一圈洞檢查，避免要求圈平面必須穿過物件底端以上。
- 目標原點以下的支撐底座保留物理碰撞，但不作為必須包覆的獎品本體；得分檢查不再因為底座邊角而拒絕已圍住獎品的圈圈。
- 必須深入原捕捉高度以下至少一個圈管直徑（目前 6 公分），避免卡在瓶蓋上便被當成套住。
- 連續穩定 0.4 秒才發分：平移速度不超過 0.25 m/s、角速度不超過 0.5 rad/s，且相對等待起點漂移不超過 1.5 公分。持續滑動或反彈不能累計穩定時間。
- 在確認期間離開圈洞或再次明顯移動會清除等待時間；若再套入，重新確認。
- GameDirector 發分入口也重新確認上述資格，不能從其他呼叫繞過等待。
- 確認後才計分與變暗，每個目標每回合僅領分一次、單一投擲最多領分一次；保留實體碰撞與重玩原色恢復。
- 20 秒截止時仍未確認的命中不加分。沒有額外寬限、放大圈洞、磁吸或凍結落圈。
- 圈圈姿態、力量、風、滑鼠靈敏度、預覽線樣式與內部輔助開關設定維持原值；輔助仍預設關閉。

截面幾何延用先前修正：SphereCollider 採截圓、CapsuleCollider 採膠囊實際截面、BoxCollider 採平面交線；其他形狀採保守包圍盒。數值容差 0.5 毫米。

## 驗證

`NightMarketScoringValidation.Begin()` 使用受控姿態與真實 PhysX，涵蓋：

- 提早發分、尚未滿等待時間、向上彈出、側向滑出、重新入圈需完整等待。
- 高速穿過有效區卻未留下、淺層瓶蓋接觸、圈緣重疊、從側面／下方插入。
- 物件池重用、退休圈圈、新回合、20 秒截止都清除或拒絕待確認命中。
- 完整穩定套住才變暗、再次投真實圈圈不重複發分、重新開始恢復全部目標。
- 真實剛體入圈後施加向上與側向速度，驗證彈出不領分。
- 46 個實際目標逐一真實落圈：初次入圈尚未計分，穩定後只發一次指定分數，最後仍包住目標、可見且變暗。

既有 `NightMarketValidation.Begin()` 的投擲觀測時間同步延長，讓新規則有時間完成穩定確認。六排中央與遠排側邊仍從實際玩家位置使用合法角度投擲，預測瓶口穿越僅代表入圈機會：最後留在圈內須發放指定分數，彈出者須保持 0 分。結果寫入 `NightMarketScoring.json` 與 `NightMarketPlayMode.json`；這些是規則與流程驗證，不能代表真人平均分數。

最新結果（Unity 6000.3.11f1）：計分專項 **115／115 通過**，包含全部 46 個目標的真實落圈、等待確認及最終留圈；流程回歸 **70／70 通過**，合計 **185／185 通過**。程式編譯通過，未另產出玩家建置。
