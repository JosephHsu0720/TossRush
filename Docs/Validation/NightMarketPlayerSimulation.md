# 夜市套圈圈：模擬玩家得分觀察

> 歷史基準：此報告為加入新瞄準輔助之前的數學瞄準模型。後續玩家實測回饋平均不到 500 分，顯示此模型高估實際操作表現；6,208 分不應用來推定真人平均。現行版本的輔助與容錯測試見 NightMarket.md。

本實驗測量具有軌跡輔助的模擬玩家，未招募真人玩家，不能據此推定真人母體平均或新手平均。

## 實驗條件

- 30 個完整回合，每回合維持遊戲原有的 **20 秒實際時間**；時間倍率為 1，物理步長不變，沒有加速、延長倒數或直接發放分數。
- 使用目前夜市關卡：46 個目標、每排高度差 45 公分、圈圈前端抬高 8 度、單個目標僅能套中一次並隱藏、動態緩慢變風。
- 優先嘗試最高分且尚未命中的目標；同分目標從較接近中央者開始。略過預計尚未落地的投擲目標，漏投後可再次嘗試。
- 第一投前瞄準 1 秒；後續每次瞄準時間均勻分布於 0.85～1.15 秒。轉向速度上限為每秒 120 度，保留遊戲的相機角度限制及投擲冷卻。
- 以目前風速及共用飛行模型計算軌跡輔助瞄準點，加入各軸標準差 0.65 度的常態隨機誤差，以及每回合各軸標準差 0.15 度的固定偏差。誤差分布是實驗假設，未由真人操作資料校準。
- 不預知後續風向；瞄準過程中風仍持續變化。從實際玩家投擲位置呼叫 `TryThrow()`，命中完全由既有碰撞與圈洞包覆判定決定。
- 最後一投若在倒數結束前尚未套中，不會補算分數。每回合分數與已領取目標的分值總和交叉核對，並檢查不超過可用總分 **10,720 分**。
- 每回合獨立重設目標與風向亂數；固定種子從 20261117 起依序遞增。保護原有最高分，結束時還原原本的輸入、音效、時間倍率與亂數狀態。

## 結果

30／30 回合全部完成，沒有執行錯誤。

| 指標 | 結果 |
| --- | ---: |
| 平均分數 | 6,208.3 分 |
| 中位數 | 6,000 分 |
| 最低／最高分 | 5,000／7,750 分 |
| 中間 80% 回合（第 10～90 百分位） | 5,500～7,250 分 |
| 每回合平均投擲次數 | 19.47 次 |
| 每回合平均命中數 | 7.57 個 |
| 總命中數／總投擲數 | 227／584 |
| 整體命中率 | 38.9% |
| 回合分數樣本標準差 | 751.7 分 |

此玩家模型平均分數的近似 95% 統計區間為 5,928～6,489 分（30 回合、Student t，29 自由度）。區間只描述此模型的回合間變異，不代表真人平均分數區間。

| 排數分值 | 30 回合總命中數 | 總得分 |
| --- | ---: | ---: |
| 20 | 0 | 0 |
| 50 | 0 | 0 |
| 100 | 0 | 0 |
| 250 | 5 | 1,250 |
| 500 | 74 | 37,000 |

得分集中在後方高分排，這與本實驗採用的「高分優先」選擇策略有關。

原始數據：同目錄 NightMarketPlayerSimulation.json 與 NightMarketPlayerSimulation.csv；每局包含亂數種子、分數、投擲數、命中數、實際計時、物理時間及各排命中數。

## 解讀限制

這個實驗可以回答「指定瞄準誤差、投擲節奏與選擇策略的玩家模型可以得到多少分」。它採用數學軌跡輔助，沒有模擬閱讀規則、發現操作方式、學習風向、注意力或個人疲勞。真人玩家的成績需要另外進行使用者測試；改變誤差、投擲節奏或選擇目標策略，也會改變平均分數。平均分數的統計區間僅描述此模型的回合間隨機變化，不包含玩家模型假設造成的不確定性。
