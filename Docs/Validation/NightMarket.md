# 夜市套圈圈特殊模式

首頁選擇 **SPECIAL MODE / RING TOSS** 進入獨立的 20 秒回合。移動滑鼠瞄準，左鍵投擲；ESC 釋放滑鼠，計時繼續。命中後留在夜市繼續投擲；結果頁可重玩同模式或選擇 MAIN MENU 返回首頁。一般模式與套圈圈分別保存最高分。

特殊模式須先於一般模式 **LET'S TOSS** 的單局達到 **1200 分**才永久解鎖。未解鎖時首頁按鈕壓暗、不可進入，按鈕內顯示 `UNLOCK: LET'S TOSS 0800 / 1200` 這類進度，使用一般模式最高分、不跨局加總。達標當下即保存解鎖，之後扣分、離開或清除最高分也不會撤回；既有一般模式最高分已達 1200 的存檔自動取得資格。特殊模式最高分不參與解鎖。解鎖後恢復原按鈕文字、色彩與操作。

共 46 個目標（原本 30 個），交錯排列於前低後高的六層實體平台；每排升高 0.45 公尺，目標基座高度依序為 0.20／0.65／1.10／1.55／2.00／2.45 公尺。攤位同步加寬，棚頂提高至 6.2 公尺，保留後排與側邊目標的投擲空間。

圈圈外徑 0.58 公尺、內半徑 0.23 公尺，使用 32 段球形碰撞體保留中空結構。手持姿態與出手姿態都以前端較高（18 度）為預設，改善淺拋時前側圈緣擦到瓶蓋的情形；出手時朝投擲水平方向轉正，保持抬頭角度。圈圈由上方接近後，會持續檢查物件中心軸與實際碰撞截面是否完整進入圈洞，包含擦邊、滑入或反彈後套住瓶身的情形。

計分必須確認「留在圈內」：圈圈須深入目標、當下完整包住目標截面，並持續穩定約 0.4 秒才發分及變暗。穿過瓶口或飛行路徑曾短暫包覆不再立即計分；尚未穩定就向上彈出或側向滑離會取消待確認命中，再次套入須重新等待。仍須在 20 秒內完成確認。

每個目標在同一回合只能得分一次，成功套中後留在原位、顏色變暗，保留碰撞體；第二個圈圈即使再次套中，也不能再次領取該目標的分數。重玩或重新進入特殊模式會恢復全部 46 個目標的原色與得分資格。變暗使用物件專屬的色彩覆寫，不修改共用材質，也不影響其他尚未命中的目標。單次投擲也最多得分一次，不附加一般模式的乾淨命中或反彈加分。

風向與強度在回合內連續緩慢變化，風向指示器與飛行中的圈圈同步使用目前風速。新軌跡預測也納入後續緩慢變風與圈緣碰撞，圈圈中心維持中空。投擲速度 15.5 m/s、額外仰角 18 度，輕量塑膠圈阻力參考面積 0.006 平方公尺。

## 玩家瞄準輔助

- 預覽線恢復使用原本的細線寬度、材質與關卡色彩；保留更新後的路徑預測。
- 啟用內部測試開關時，顯示與真實圈圈相同姿態與尺寸的落點圈；碰到障礙的圈呈橘色。
- 可以套入時落點圈轉綠、標出目標並顯示 READY +分數。需要調整時顯示向上、向下、向左或向右瞄準的提示。
- 剩餘時間不足以落地時不顯示綠色 READY，改為提示投向近排，避免倒數將結束時誤以為還能得分。
- `Enable Aim Assist For Testing` 同時控制出手方向修正、落點圈、綠色目標標記及 READY／調整方向提示，**預設關閉**，不提供玩家選項、快捷鍵或玩家偏好儲存。關閉時以原始瞄準方向投擲，只保留原本樣式的細預覽線與一般操作文字。
- 開發者可在玩家物件的 `RingAimGuidance` Inspector 中切換 `Enable Aim Assist For Testing`。開啟時，接近有效方向的投擲最多修正 1.8 度；預覽與實際投擲使用同一速度，得分仍通過實際圈洞包覆判定。驗證工具會自行開啟並於結束時還原開關。
- 夜市與一般模式均使用原本的滑鼠靈敏度，不再套用夜市專屬倍率。

預設操作方式：移動滑鼠瞄準、參考細預覽線後左鍵投擲。內部測試開關開啟時，可再參考落點圈與綠色 READY +分數提示。

- 回合內緩慢變風，以及飛行中的圈圈受到風力影響。
- 固定 20 秒倒數、重玩、返回首頁、一般模式原有六關與命中換關。
