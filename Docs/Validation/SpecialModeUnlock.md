# 特殊模式解鎖

一般模式 LET'S TOSS 的單局分數達到 1200 即永久解鎖。未解鎖時按鈕壓暗、不可進入，按鈕內以兩行顯示模式名稱及 `UNLOCK: LET'S TOSS 0800 / 1200`。進度使用一般模式最高分，不跨局累計；特殊模式分數不參與解鎖。

達標當下以 `TossRush.RingToss.Unlocked.v1` 保存，不需等結算；後續扣分、返回選單、清除最高分均不撤回資格。既有一般模式最高分至少 1200 者直接取得資格並保存。解鎖後恢復原按鈕文字、字色與操作。

開發時重測：停止 Play Mode，選擇 **TossRush → 測試工具**。視窗顯示兩種模式最高分及目前解鎖狀態，提供兩個操作：

- **Clear High Score**：同時清除一般模式與特殊模式最高分，保留已取得的解鎖資格。
- **Reset Special Mode Unlock**：清除一般模式最高分及解鎖紀錄，保留特殊模式最高分，再開始 Play Mode 即恢復鎖定。

兩個操作僅能於停止 Play Mode 時使用，避免回合結束後又寫回測試中的分數。原本的兩個獨立選單已整合至此視窗。

同一視窗也提供「固定關卡測試」，可選擇一般模式六個關卡並固定重複，或恢復正常輪替；這部分可在 Play Mode 中使用。
